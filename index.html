How OpportunityLens Uses TinyFish Web Agent APIs

OpportunityLens uses TinyFish not as a decorative wrapper, but as the core autonomous discovery & verification engine that powers every search, URL scan, and skill extraction across the platform.

01. TinyFish Search API

Discovers live career pages, research fellowships, Web3 bug bounties, and university portals matching student intent.

GET https://api.search.tinyfish.ai?q={query}
02. TinyFish Fetch API

Converts complex JavaScript-rendered job listings into clean, structured markdown for skill & stipend extraction.

POST https://api.fetch.tinyfish.ai
03. TinyFish Web Agent SSE

Executes multi-step browser actions on target portals and streams real-time Server-Sent Events (SSE) to the UI.

POST https://agent.tinyfish.ai/v1/automation/run-sse

Server-Side Security & Hybrid Resilience

All requests route through /api/tinyfish/run-sse (`server.py`, `server.js`, and Vercel Serverless Functions) reading TINYFISH_API_KEY from environment variables so keys are never leaked in client source code.
