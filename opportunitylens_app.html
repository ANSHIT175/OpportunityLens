TinyFish API Playground & Server Security

All requests are proxied through your backend (server.py / server.js) using the server-side TINYFISH_API_KEY environment variable. Your API key is never exposed in browser JavaScript.

1. Server-Side `TINYFISH_API_KEY` Status

For security, TINYFISH_API_KEY is read exclusively on the backend server via os.environ["TINYFISH_API_KEY"] and injected as the X-API-Key HTTP header.
